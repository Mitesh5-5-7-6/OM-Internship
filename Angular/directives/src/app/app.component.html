Directives are 'enhancements' for elements (built-in ones or components)

Directive is a class that adds additional behavior to elements in your application.
angular that help you to provide more power to DOM elements if-else, for loop, add style, ngIf, ngFor, ngStyle, ngSwitch, etc.


Component Directives

most common type of directive

Used in Component template file


Structural Directives

*ngIf,*ngFor,... *

Change the DOM Structural by adding, removing,..

Ex : toggle, add btn,..


Attribute Directives

Modify the appearance or behavior of an existing element

ngClass, ngStyle
